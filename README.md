### Flagship Systems & Open Source

* **[SkillForge](https://github.com/gintingism/skillforge)** (`agent-skillforge`)  
  *CLI & Model Context Protocol (MCP) Runtime for AI Agent Skills*  
  Open-source developer CLI to author, validate, and package `SKILL.md` agent skills, featuring an integrated Python MCP server for Claude Code, Cursor, and Copilot.

* **[Gintingmology v3.0](https://gintingmology-idx-stock-analyzer.vercel.app/)**  
  *IDX Quantitative Market Intelligence & Trading Terminal*  
  Full-stack financial terminal with Real-Time VSA Cockpit, Multi-Factor Quant Screener, 9-Sector Macro Barometer, and Groq LPU (Llama 3.3 70B) synthesis.  
  *Stack: Next.js, FastAPI (Pandas/NumPy), Supabase PostgreSQL & RLS.*

* **[Jakarta Transit Pulse](https://jakarta-transit-pulse.vercel.app/)**  
  *Greater Jakarta Multi-Modal Transit Companion*  
  Commuter navigation engine integrating KRL, MRT, LRT, and TransJakarta with Haversine Geo-Alarms (Anti-Kebablasan) and offline Web Audio alarm synthesis.  
  *Stack: Next.js, TypeScript, Tailwind CSS, Haversine Engine (98/100 Mobile Lighthouse Score).*

* **[Carita: Tuappaka Sisarikbattang](https://drive.google.com/file/d/1Y5NIJ52YwPhJauLuHwzAukiZGBJnFhOx/view?usp=drive_link)**  
  *Augmented Reality Folklore iOS App (Apple App Store)*  
  Interactive folklore storytelling iOS app developed at Apple Developer Academy C5 linking physical story cards with real-time 3D scenes.

* **[Enterprise Architecture & Database Blueprints](https://drive.google.com/drive/folders/1dFgPWLGKcCXHMw1Vx4MKnkntjkmcFYMx?usp=drive_link)**  
  Academic formal specifications including the *Kindness Platform* (Three-Tier OOAD separation of concerns) and *Traveloka Flight Booking Engine* (Third Normal Form relational model with ARC exclusive subtype constraints and immutable point-in-time fare snapshots).
